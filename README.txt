LUNGTA - One Page Interactive Website

Run locally:
1. Unzip this folder.
2. Double-click index.html for a quick preview, OR use any local/static host.
3. For best browser behaviour, serve the folder through HTTP (Netlify Drop, Cloudflare Pages, GitHub Pages, Vercel static, cPanel/public_html, etc.).

No build step. No npm. No framework. No external CDN dependencies.
Files:
- index.html
- styles.css
- script.js
- assets/

The email form is a front-end demo interaction only. Connect it to your preferred email/CRM endpoint before production if you want to collect real addresses.
